# Rivers & Roots Landscaping Demo

A ready-built Fireworks website for a Pittsburgh-area landscaping company. The visible business identity, phone number, and email address are fictional and intentionally labeled as demo content.

## Commands

```bash
npm run check
npm run build
```

Vercel serves the generated `dist/` directory with clean URLs.

## Before customer launch

- Replace the demo company identity and all contact details.
- Replace stock photography with approved customer work where available.
- Connect the quote form to the customer's approved email, CRM, or form service.
- Replace the canonical domain and social sharing URLs.
- Remove `noindex` meta tags and the robots.txt disallow rule only after all details are verified.
- Add truthful LocalBusiness schema using the customer's actual address or service-area details, phone, hours, and profiles.
